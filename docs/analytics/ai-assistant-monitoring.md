# AI Assistant traffic monitoring

## Current baseline

The latest available export attributes 6 sessions to `AI Assistant`, with 50%
engaged sessions and 2 key events. This is a useful signal, not a trend or a
basis for paid investment decisions.

Keep this channel separate from Organic Search in monthly reporting. Compare it
with Direct, Organic Search and Referral using the same date range and landing
page scope.

## GA4 report

Use the **Traffic acquisition** report with these dimensions and metrics:

| Dimension | Why it matters |
| --- | --- |
| Session primary channel group | Confirms whether GA4 still labels the source `AI Assistant`. |
| Session source / medium | Shows the referring source when GA4 exposes it. |
| Landing page + query string | Identifies which commercial or article pages are being cited. |
| `page_language` event parameter | Separates `/`, `/ca/` and `/en/`; register it as a GA4 custom dimension if it is not already available in reports. |
| Sessions and engaged sessions | Measures volume and quality. |
| Event name | Tracks `contact_cta_click`, `contact_whatsapp_click`, `service_link_click` and `generate_lead`. |

Filter once for `Session primary channel group = AI Assistant`, then repeat the
same report without the filter for comparison. Record the actual
`session_source` and `session_medium` values returned by GA4; do not infer a
fixed rule from the channel label. Export the result monthly with the date
range and export date in the filename.

## Content coverage

The commercial pages answer the questions an assistant needs to summarise the
service accurately:

- DJ for weddings: service scope, ceremony/cocktail/party coverage, repertoire,
  destination weddings, supplier coordination and Costa Brava/Girona coverage.
- Corporate production: event formats, sound, lighting, music, coordination,
  external suppliers, scope and proposal process in Girona and Costa Brava.
- Articles: contextual links to the relevant commercial page and contact CTA.

Keep answers visible, specific and consistent with the linked commercial page.
Do not create repeated AI-specific copy or hidden text.

## Controlled links

Use the UTM inventory in `docs/analytics/utm-inventory.md` for links that the
team controls. Referrals generated by assistants cannot be reliably tagged at
source, so preserve the GA4 channel and source/medium fields rather than
inventing attribution.

## Decision rule

Do not change budgets or positioning from the current six-session sample. After
30-60 days, review trend, landing pages, engaged sessions, contact CTA clicks
and confirmed leads. Treat a channel as actionable only when it shows repeated
commercial activity across more than one reporting period.
